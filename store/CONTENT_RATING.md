# Content rating and target audience

| Topic | Answer |
|---|---|
| Violence | No |
| Fear / horror | No |
| Sexuality / nudity | No |

| Controlled substances (drugs, alcohol, tobacco) | No |
| Gambling / simulated gambling | No |
| Crude humour | No |
| User-generated content shared with other users | No — nothing is uploaded or shown to other users; sharing is through the system share sheet only |

| Ads | **Yes** (Google AdMob; banner on Home, occasional interstitial after export) |

**Expected rating: Everyone** (ESRB Everyone, PEGI 3, USK 0, ClassInd L).

## Target audience and content
- **Target age groups: 13–15, 16–17, 18 and over.**
- Not designed for children under 13, so the app is not in the Families programme and its
  stricter ad rules do not apply.
- "Could your app unintentionally appeal to children?" — the design is neutral (no cartoon
  characters, no child-focused content); answer **No**.
- Ads: the app contains ads (Google AdMob). AdMob requests are not tagged for child-directed
  treatment.
